# Iconoir icon reference

## Naming convention

All icon filenames use **kebab-case** with a `.svg` extension. The name tells the visual meaning of the icon, for example `arrow-right`, `warning-circle`, and `shopping-bag`. Related icons have a common prefix, for example `arrow-*`, `phone-*`, and `database-*`.

## When to use regular or solid

| Context | Variant | Reason |
| --- | --- | --- |
| Navigation menus, toolbars | `regular` | Lighter visual weight for chrome |
| Inactive/default toggle state | `regular` | Shows "off" or "unselected" |
| Active/selected toggle state | `solid` | Filled shape shows "on" or "selected" |
| Status badges, notifications | `solid` | Filled shape gets attention |
| Next to body text | `regular` | Matches the stroke weight of text |
| Call-to-action buttons | `solid` | Adds visual emphasis |

## Integration

To get full control of the style, put the SVG inline in the HTML:

```html
<svg width="24" height="24" viewBox="0 0 24 24" stroke-width="1.5" fill="none" xmlns="http://www.w3.org/2000/svg">
  <path d="M3 12L21 12M21 12L12.5 3.5M21 12L12.5 20.5" stroke="currentColor" stroke-linecap="round" stroke-linejoin="round"/>
</svg>
```

To change the size, set `width` and `height` on the `<svg>` element. The `viewBox="0 0 24 24"` makes sure that the icon scales proportionally.

To change the color, set `color` on the SVG or on a parent element. The `currentColor` value on `stroke` gets this color automatically. On solid variants, the `currentColor` value on `fill` also gets this color.

## Browse the full set

To see all the icons, list the asset directories:

- Regular (outline): `assets/icons/regular/` (1383 icons)
- Solid (filled): `assets/icons/solid/` (288 icons)

Each filename is the icon name plus `.svg`. For a visual catalog, go to the [Iconoir website](https://iconoir.com/).
