# Iconoir Icon Reference

## Naming Convention

All icon filenames use **kebab-case** with a `.svg` extension. The name describes the icon's visual meaning (e.g., `arrow-right`, `warning-circle`, `shopping-bag`). Related icons share a common prefix (e.g., `arrow-*`, `phone-*`, `database-*`).

## Regular vs Solid Usage

| Context | Variant | Rationale |
| --- | --- | --- |
| Navigation menus, toolbars | `regular` | Lighter visual weight for chrome |
| Inactive/default toggle state | `regular` | Reads as "off" or "unselected" |
| Active/selected toggle state | `solid` | Fills in to signal "on" or "selected" |
| Status badges, notifications | `solid` | Draws attention with filled shape |
| Paired with body text | `regular` | Matches text stroke weight |
| Call-to-action buttons | `solid` | Adds visual emphasis |

## Integration

Inline the SVG directly for full styling control:

```html
<svg width="24" height="24" viewBox="0 0 24 24" stroke-width="1.5" fill="none" xmlns="http://www.w3.org/2000/svg">
  <path d="M3 12L21 12M21 12L12.5 3.5M21 12L12.5 20.5" stroke="currentColor" stroke-linecap="round" stroke-linejoin="round"/>
</svg>
```

To resize, set `width` and `height` on the `<svg>` element. The `viewBox="0 0 24 24"` ensures proportional scaling.

To recolor, set `color` on the SVG or a parent element — the `currentColor` value on `stroke` (and `fill` for solid variants) inherits automatically.
